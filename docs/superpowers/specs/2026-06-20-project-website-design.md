# 古建筑损伤检测系统 — 项目展示网站设计文档

> 日期：2026-06-20 | 状态：已确认

---

## 一、项目背景

为「古建筑损伤智能检测系统」比赛项目搭建配套展示网站，同时面向：

- **比赛评委**：快速了解项目亮点，评估技术深度和完整度
- **潜在用户**（文保单位、古建修缮公司）：了解功能后下载使用

## 二、网站定位

单页滚动展示网站（Landing Page），纯静态 HTML/CSS/JS，部署于 GitHub Pages。通过 GitHub Releases 分发可执行文件。

## 三、技术选型

| 项目 | 选择                   | 理由                                 |
| ---- | ---------------------- | ------------------------------------ |
| 前端 | 纯静态 HTML + CSS + JS | 零依赖，完全控制视觉风格，写完即部署 |
| 托管 | GitHub Pages           | 免费、专业、支持自定义域名           |
| 下载 | GitHub Releases        | 支持大文件（2GB），带版本管理        |
| 语言 | 纯中文                 | 受众均为中文用户                     |

## 四、页面结构

单页，5 个段落从上到下滚动，顶部固定导航栏 + 右侧圆点位置指示器。

- 两个 CTA 按钮：「下载软件」（主按钮，朱砂红） + 「了解更多」（次按钮，铜金边框）

### 4.2 核心功能

- 6 张功能卡片网格排列（2×3 或 3×2）

## 五、视觉设计

### 5.1 配色方案

延续桌面应用的「宣纸古建」主题：

| 颜色     | 色值      | 用途                   |
| -------- | --------- | ---------------------- |
| 宣纸米白 | `#FAF6EE` | 页面背景               |
| 朱砂红   | `#B84C3B` | 主按钮、强调色、链接   |
| 铜金     | `#C4A66A` | 边框、分隔线、次要装饰 |
| 深棕     | `#4A3728` | 标题文字               |
| 褐色     | `#8B7355` | 正文文字、描述         |

### 5.2 字体

- **标题**：思源宋体（Noto Serif SC），降级为系统衬线字体。呼应传统匾额题字感
- **正文**：微软雅黑，降级为系统无衬线。保证可读性

### 5.3 设计元素

- 卡片采用铜金细边框 + 米白底色，仿宣纸质感
- 按钮主样式为朱砂红实色，hover 加深；次要样式为透明底 + 铜金边框
- 分隔线使用铜金色细线
- 背景可加入隐约的宣纸纹理（CSS 实现或 SVG）

### 5.4 响应式

- 桌面端（>1024px）：3 列卡片 / 居中布局，最大宽度 1200px
- 平板端（768-1024px）：2 列卡片
- 手机端（<768px）：单列，缩小间距和字号

## 六、技术实现要点

### 6.1 文件结构

```
docs/website/
├── index.html          # 唯一的 HTML 页面
├── css/
│   └── style.css       # 全部样式
├── js/
│   └── main.js         # 滚动动画、导航高亮
└── img/
    ├── screenshot-1.jpg    # 检测界面截图
    ├── screenshot-2.jpg    # 热力图截图
    ├── screenshot-3.jpg    # PDF报告截图
    └── favicon.png         # 网站图标
```

### 6.2 关键功能

- **平滑滚动**：点击导航项平滑滚动到对应段落（CSS `scroll-behavior: smooth` + JS polyfill）
- **导航高亮**：监听滚动位置，当前段落对应导航项高亮（Intersection Observer）
- **滚动动画**：内容块进入视口时淡入（Intersection Observer + CSS transition）
- **下载按钮**：链接到 GitHub Releases 最新版本 URL

### 6.3 部署流程

1. 将 `docs/website/` 目录内容推送到 GitHub 仓库
2. 在仓库 Settings → Pages 中启用，选择 `main` 分支 `/docs` 目录
3. 在 Releases 页面创建新版本，上传 `古建筑损伤检测系统.zip`
4. 网站下载按钮链接到 Releases 的 zip 文件 URL
